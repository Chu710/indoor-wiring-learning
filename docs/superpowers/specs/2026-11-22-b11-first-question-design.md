# 室內配線丙級 B11 第一題與多題術科架構設計規格

## 目標

在保留現有 B11 第二題全部功能與資料的前提下，新增 B11 第一題「屋內線路與手動、自動液位控制電路之裝置」，並將術科頁面改為可擴充的多題練習系統。

成功標準：

- 使用者可以在術科頁面切換第一題與第二題。
- 每題分別保存接線草稿、元件位置、計時、錯誤、提示及完成紀錄。
- 第一題能檢查官方圖面的必要節點、危險接法及控制功能。
- 正確接線後能模擬手動、自動液位、缺水警報、警報停止、過載及復歸。
- 第一題沿用第二題目前的固定內部線槽、單線高亮與接線清單。
- 第二題既有接線、檢查、通電模擬與學科功能不得退化。

## 官方依據

來源為勞動部 `007003B11.pdf`：

- 第一題功能要求：印刷頁 3-7。
- 第一題工作圖：印刷頁 8。
- 第一題手動、自動液位控制電路圖：印刷頁 9。
- 第一題器具位置圖：印刷頁 10。

程式內新增的端子名稱只作教學識別；官方圖未標示的實體端子號不得宣稱為現場配線標準。畫面保留安全聲明，要求實際施工時核對官方圖、器材型號及指導教師。

## 方案選擇

採用「共用接線引擎 + 題目資料模組 + 題目專屬模擬器」。不複製整套第二題頁面，也不把第一題縮減成只能看圖與接線的靜態練習。

共用層負責：

- 題目選擇與共用版面。
- 元件、端子、電線、固定線槽及單線追蹤。
- 無向連線圖、必要節點檢查、危險接線攔截及分段提示。
- 草稿與完成紀錄的序列化。

題目專屬層負責：

- 元件清單、端子、初始位置、標準節點與危險端點組合。
- 分段練習內容與官方電路圖。
- 通電模擬狀態、操作按鈕、預期結果及完成條件。

## 資料與模組架構

建立共用 `PracticalQuestion` 定義，至少包含：

- `id`、題號、標題、官方來源與電路圖資源。
- 元件、端子、初始位置、參考節點、固定連線及危險端點。
- 分段練習定義。
- 模擬器種類及對應操作定義。

預定模組邊界：

- `src/practical/types.ts`：共用題目、元件、端子、電線與診斷型別。
- `src/practical/questions.ts`：題目清單與題號查找。
- `src/practical/graph.ts`、`validate.ts`、`session.ts`：由現有 B11 共用能力整理而來。
- `src/practical/q1/`：第一題資料、分段、液位控制模擬與測試。
- `src/practical/q2/`：第二題既有資料與正反轉模擬；可先以重新匯出方式搬移，避免一次大改。

第二題現有公開介面先保留相容匯出，讓既有測試持續運作；待兩題功能穩定後才移除舊路徑。

## 第一題器材與工作區

第一題至少呈現以下教學元件：

- 單相 220V 電源、NFB 及兩個控制保險絲。
- 電磁接觸器 MC、積熱電驛 TH-RY、單相馬達。
- 液位控制器 61F-G1 與水槽／給水源電極。
- 手動／自動選擇開關 COS。
- PB1 啟動、PB2 停止、PB3 警報停止。
- 綠燈 G、紅燈 R、黃燈 Y、蜂鳴器 BZ。
- 官方圖所需的端子台、保護接地與箱內／箱外連接端子。

箱內元件與操作面板依官方器具位置圖分區。工作區延用固定內部線槽；每個元件必須放在線槽形成的格子內，任何參考接線不得穿過其他元件或使用箱體外框繞線。

## 第一題接線判定

答案以電氣節點而非繪線座標判定，允許同一節點內的電氣等效接法。檢查順序：

1. **危險錯誤**：電源短路、保護接地接到帶電端、控制保護被旁路或接觸器線圈直接跨接電源。
2. **結構錯誤**：必要節點缺線、端子接錯、液位電極／端子台路徑缺失。
3. **功能錯誤**：手動自保持、停止、液位啟停、缺水保護、蜂鳴器停止或過載保護無法成立。

提示仍分三層：問題區域、相關功能／元件、相關端子方向。完整參考接線只在使用者主動要求時顯示並記錄提示使用。

## 第一題通電模擬

使用離散狀態模擬，不計算實際水量、電流或電極阻抗。

### 手動模式

- COS 在手動位置時，PB1 使 MC 吸合並自保持，馬達開始抽水。
- PB2 使 MC 釋放，馬達停止。
- 手動模式仍受過載與缺水保護約束，不允許繞過安全條件。

### 自動液位模式

- 給水源水位低於低水位電極時，馬達不得運轉，蜂鳴器鳴叫。
- 給水源具備允許抽水的水位且水槽低於低水位時，馬達自動啟動。
- 水槽到達高水位時，馬達自動停止。
- 馬達運轉中若給水源降至缺水狀態，馬達立即停止並啟動蜂鳴器。
- PB3 可停止蜂鳴器，但不能清除缺水條件或強制馬達運轉。

### 指示與保護

- 電源正常且 MC 釋放時：綠燈亮、紅燈滅。
- MC 吸合時：紅燈亮、綠燈滅。
- TH-RY 跳脫時：MC 釋放、馬達停止、黃燈亮；依官方要求顯示對應綠燈狀態。
- 未復歸 TH-RY 前不得重新啟動；復歸後黃燈熄滅。

模擬面板提供：COS 手動／自動、PB1、PB2、PB3、水槽低／中／高水位、給水源缺水／允許／充足、過載跳脫及復歸。只有接線檢查通過後才能操作通電模擬。

## 題目切換與本機資料

術科頁面新增「第一題／第二題」切換器。切換時：

- 先保存目前題目的草稿，再載入目標題目的草稿。
- 不共用電線、元件位置、開始時間、檢查次數、提示次數或模擬狀態。
- 已完成紀錄以題目 ID 分組顯示。
- 第二題舊版草稿仍可讀取；讀取後使用目前的題目 ID 與格式重新保存。
- 「重新開始」只清除目前題目的未完成草稿，不影響另一題及歷史紀錄。

若草稿格式無效或題目 ID 不存在，忽略該份草稿並顯示可理解的警告，不載入跨題資料。

## 畫面流程

1. 使用者進入術科配線，選擇第一題或第二題。
2. 顯示該題的官方圖、元件庫、固定線槽工作區、分段練習及通電面板。
3. 使用者接線並逐段檢查；錯誤只標示目前題目的相關區域。
4. 全部接線通過後，解鎖該題專屬模擬操作。
5. 第一題須完成手動啟動／停止、自動低水位啟動、高水位停止、缺水警報、PB3 消音、過載及復歸測試。
6. 完成後保存紀錄；切換題目不會清除結果。

## 測試策略

### 題目資料測試

- 所有端子 ID 唯一，參考節點只引用存在端子。
- 第一題官方必要節點與接地路徑完整。
- 所有元件不覆蓋固定線槽，全部參考路徑不穿越元件或箱體外框。

### 規則與模擬測試

- 正確接線可通過，缺線、錯接、短路及接地錯誤會被攔截。
- 手動啟動、自保持、停止及過載行為正確。
- 自動低水位啟動、高水位停止及缺水禁止運轉正確。
- 運轉中缺水會停止並鳴叫，PB3 只消音不解除缺水。
- 燈號、蜂鳴器、MC 與馬達狀態符合官方功能要求。

### 畫面與儲存測試

- 題目切換會保存並恢復各自草稿。
- 第一題與第二題的計時、錯誤、提示及完成紀錄互不污染。
- 兩題都能載入參考接線、追蹤單線及刪除電線。
- 第二題既有完整流程測試保持通過。

### 瀏覽器驗收

- 筆電寬度下題目切換、元件庫、工作區與任務面板不互相遮擋。
- 第一題完整參考接線可清楚追蹤，選取線明亮、其他線淡化。
- 切換兩題再返回時，未完成接線仍存在。
- 第一題正確接線後可完成全部模擬測試並產生一筆完成紀錄。

## 不在本階段範圍

- 第三題及第四題。
- 真實水位連續物理模擬、電流、電壓降或電極阻抗計算。
- 現場器材品牌端子號的保證。
- 真實 110／220V 電源控制、攝影機辨識或硬體連線。
- 帳號、雲端同步、教師後台及多人資料管理。

## 驗收條件

- 第一題與第二題可在同一術科頁面切換並獨立續作。
- 第一題標準接線與允許的電氣等效接線可通過檢查。
- 已知危險接法一定在通電前被攔截。
- 第一題的手動、自動液位、缺水、消音、過載與復歸行為全部可驗證。
- 第一題所有參考電線只走內部固定線槽且不穿過元件。
- 完整自動測試、TypeScript 建置及瀏覽器驗收通過，且第二題功能沒有回歸。
