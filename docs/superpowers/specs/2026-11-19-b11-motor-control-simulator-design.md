# 室內配線丙級 B11 第二題接線模擬器設計規格

## 專案目標

建立一套以筆記型電腦操作的室內配線丙級術科練習系統。第一階段聚焦 B11 第二題的馬達正反轉控制，讓學習者透過拖曳電線完成端子接線，系統能判斷危險接法、缺線、端子錯誤與控制邏輯錯誤，最後執行通電模擬。

本階段的成功標準如下：

- 學習者可在單一桌面頁面完成元件配置與端子接線。
- 系統能正確判斷標準答案允許的等效接線。
- 系統能指出短路、缺線、錯接與互鎖失效，但不會立即公布完整答案。
- 正確接線後，可測試正轉、停止、反轉、電氣互鎖與過載跳脫。
- 系統可在本機記錄完成時間、錯誤次數與提示次數，供後續論文分析使用。

## 第一階段範圍

### 包含

- B11 第二題馬達控制箱練習。
- 可拖曳的電氣元件。
- 可從端子拉到端子的電線。
- 紅、白、黑、綠四色線材。
- 電線選取、刪除與重新接線。
- 分層接線檢查與逐步提示。
- 正轉、反轉、停止、互鎖及過載通電模擬。
- 本機練習紀錄。

### 暫不包含

- 學科題庫與前後測。
- 使用者登入、雲端同步與教師後台。
- 手機版操作最佳化。
- B11 其他題目或其他職類題組。
- 真實硬體或攝影機辨識整合。

## 技術架構

採用 React、TypeScript 與 SVG 建立本機優先的單頁應用程式。

- React 負責元件狀態、面板與操作流程。
- SVG 負責電線、端點與工作區連線視覺。
- TypeScript 定義元件、端子、連線、規則與模擬狀態，避免題目擴充時資料格式失控。
- 瀏覽器 `localStorage` 保存未完成練習及練習紀錄。
- 第一版不需要後端服務。

系統分成四個獨立模組：

1. **題目資料模組**：定義 B11 第二題需要的元件、端子、初始位置與合法連線。
2. **接線工作區模組**：處理元件拖曳、端子選取、電線繪製、刪除與線色。
3. **規則與模擬模組**：以電路圖資料判斷短路、缺線、錯接、互鎖與通電結果。
4. **練習紀錄模組**：記錄開始時間、完成時間、錯誤次數、提示次數與是否完成。

題目資料與畫面元件分離，之後新增其他題目時只需加入新的題目定義與必要元件，不必重寫接線引擎。

## 畫面配置

頁面以筆電寬螢幕為主要尺寸，分為三欄：

- **左側元件庫**：單相電源、無熔絲開關、正反轉電磁接觸器、積熱電驛、按鈕、指示燈與單相感應電動機等元件。
- **中央工作區**：控制箱與接線區，支援元件拖曳、縮放、端子連線與電線選取。
- **右側任務面板**：顯示步驟、線色選擇、檢查接線、提示、清除電線與通電測試。

上方顯示題目名稱、目前階段、經過時間與練習重新開始。危險狀態使用紅色，未完成提示使用橙色，正確與通電狀態使用綠色；不能只靠顏色傳達結果，必須同時顯示文字或圖示。

## 主要操作流程

1. 學習者進入 B11 第二題並開始計時。
2. 從左側元件庫將元件拖入中央工作區。
3. 選擇線色，從一個端子拖曳至另一個端子建立電線。
4. 學習者可選取電線刪除或重新連接。
5. 按下「檢查接線」後，系統依序檢查危險錯誤、結構錯誤及控制邏輯錯誤。
6. 若有錯誤，只標示問題元件或線路；學習者可主動要求逐步提示。
7. 接線正確後解鎖通電測試。
8. 學習者操作正轉、停止、反轉與過載測試，系統顯示接觸器、指示燈及馬達狀態。
9. 所有測試通過後完成練習並保存紀錄。

## 接線資料模型

每個元件具有唯一 ID、類型、位置與端子清單。每個端子具有唯一 ID、顯示標籤、用途與可接受的線色。每條電線記錄起點端子、終點端子、線色與建立時間。

判定不依賴畫面座標，而是將連線轉成無向電路圖。合法答案以必要電氣節點和功能條件描述，因此同一節點內不同但電氣等效的接線仍可判定正確。

## 錯誤判定與提示

檢查順序固定如下：

1. **危險錯誤**：可能造成短路、直接跨接電源或使互斥接觸器同時吸合。
2. **結構錯誤**：缺少必要連線、接到錯誤端子或使用不允許的端點組合。
3. **功能錯誤**：自保持、停止、正反轉互鎖或過載保護邏輯無法成立。

提示採三層設計：

- 第一層只指出問題區域。
- 第二層說明應檢查的元件或功能。
- 第三層顯示相關端子方向，但仍不直接繪出整份答案。

只有在學習者主動要求最終答案時，才顯示正確接線參考；此行為需記錄為使用提示。

## 通電模擬規則

- 正轉按鈕只能使正轉接觸器吸合，並啟動正轉狀態。
- 反轉按鈕只能使反轉接觸器吸合，並啟動反轉狀態。
- 正轉與反轉接觸器不得同時吸合。
- 停止按鈕需中斷目前運轉。
- 正確的自保持迴路可在放開啟動按鈕後維持運轉。
- 過載跳脫後，所有運轉狀態停止，且在復歸前不能再次啟動。
- 指示燈狀態必須與接觸器及故障狀態一致。

## 本機紀錄

每次練習保存以下欄位：

- 題目 ID。
- 開始時間與完成時間。
- 是否完成。
- 接線檢查次數。
- 危險錯誤、結構錯誤與功能錯誤次數。
- 各層提示使用次數。
- 通電測試結果。

重新整理頁面後應可恢復未完成的接線狀態。使用者選擇「重新開始」時，先顯示確認提示，再清除目前題目的未完成狀態；已完成的歷史紀錄保留。

## 錯誤處理

- 未選擇有效端子時，不建立電線並顯示簡短原因。
- 重複連線不建立第二條相同電線。
- 不支援的線色或端子組合在建立前阻止。
- 本機儲存失敗時，練習仍可繼續，但畫面需警告紀錄可能無法保留。
- 題目資料無效時停止載入該題，顯示可理解的錯誤訊息，不呈現不完整電路。

## 測試策略

### 單元測試

- 電路圖建立與等效節點判定。
- 危險接法、缺線、錯接與互鎖失效偵測。
- 正轉、反轉、停止、自保持與過載狀態轉換。
- 練習統計與本機資料序列化。

### 元件測試

- 端子選取與拉線。
- 電線刪除與線色變更。
- 分層提示顯示。
- 通電測試按鈕的可用狀態。

### 瀏覽器流程測試

- 完整正確接線可以完成所有通電測試。
- 危險接線無法進入通電階段。
- 重新整理後可以恢復未完成練習。
- 完成後會產生正確的練習紀錄。

## 驗收條件

- 在一般筆電寬度下，三欄操作區不互相遮擋，主要文字不小於 14 像素。
- 學習者不需要閱讀說明文件即可完成拉線、刪線、檢查與通電操作。
- 標準正確接線與電氣等效接線皆可通過。
- 已知危險接法一定會在通電前被攔截。
- 五項通電行為：正轉、停止、反轉、互鎖、過載皆可驗證。
- 練習完成後可查看時間、錯誤次數與提示次數。

## 後續擴充方向

完成第一階段並經使用者測試後，再依序考慮：

1. B11 其他術科題目。
2. 室內配線學科前測與後測。
3. 教師匯出學習紀錄。
4. 帳號、雲端同步與班級管理。
5. 真實器材或影像辨識輔助。
