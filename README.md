# 室內配線丙級 B11 第二題接線練習

這是筆電瀏覽器使用的控制迴路練習原型，用來示範單相感應電動機的正轉、反轉、停止、電氣互鎖與過載狀態。接線檢查目前只涵蓋控制迴路，尚未通過官方 B11 第二題完整驗證，不應作為實體配線或考試正解。

## 啟動

安裝 Node.js 20.19 以上與 pnpm 後，在本資料夾執行：

```powershell
pnpm install
pnpm dev
```

打開終端顯示的本機網址，通常是 `http://127.0.0.1:5173/`。測試用 `pnpm test`，正式建置用 `pnpm build`。

## 操作

1. 在左側查看元件；可以拖曳元件到中央調整位置。
2. 選擇線色，依序點兩個端子接線；也可從一個端子拖到另一個端子。
3. 在工作區下方點選已接電線可刪除；點「檢查示範接線」查看第一個待修正問題。
4. 需要時逐層開啟提示，或主動顯示參考接線。
5. 接線通過後，測試正轉、停止、反轉、互鎖與過載。

重新整理可恢復未完成接線。完成時間、檢查錯誤與提示次數只儲存在這台電腦的瀏覽器內。清除瀏覽器網站資料會刪除這些紀錄。

## 範圍與限制

官方 `007003B11.pdf` 第二題附圖（二）包含接線端子台、馬達繞組、正反轉主電路及保護接地。這些主電路部分尚未建模或評分。控制狀態按鈕由程式直接切換，沒有根據所接電路計算。畫面上的數字端子是教學標示，並非現場器材配置。使用前應以官方圖、現場器材型號與指導教師確認實際配線；本程式不會控制真實電源。

目前只有一個題目，沒有帳號、雲端、學科題庫或教師後台。
