# 室內配線丙級 B11 第二題接線練習

這是筆電瀏覽器使用的互動教學初版，聚焦單相感應電動機的正轉、反轉、停止、電氣互鎖與過載保護。

## 啟動

安裝 Node.js 20.19 以上與 pnpm 後，在本資料夾執行：

```powershell
pnpm install
pnpm dev
```

打開終端顯示的本機網址，通常是 `http://127.0.0.1:5173/`。測試用 `pnpm test`，正式建置用 `pnpm build`。

## 操作

1. 在左側查看元件；可以拖曳元件到中央調整位置。
2. 選擇線色，依序點兩個端子接線；也可從一個端子拖到另一個端子。
3. 在工作區下方點選已接電線可刪除；點「檢查接線」查看第一個待修正問題。
4. 需要時逐層開啟提示，或主動顯示參考接線。
5. 接線通過後，測試正轉、停止、反轉、互鎖與過載。

重新整理可恢復未完成接線。完成時間、檢查錯誤與提示次數只儲存在這台電腦的瀏覽器內。清除瀏覽器網站資料會刪除這些紀錄。

## 範圍與限制

題目依勞動部 `007003B11.pdf` 的第二題附圖（二）控制原理建立。官方圖未逐一列出每個器材接點的實體端子號，畫面上的數字端子是教學標示，並非現場器材端子配置圖。電動機在此版本以負載端兩個接點表示，未模擬其內部繞組與電容接線。使用前應以官方圖、現場器材型號與指導教師確認實際配線；本程式不會控制真實電源。

目前只有一個題目，沒有帳號、雲端、學科題庫或教師後台。
