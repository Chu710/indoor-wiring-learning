# 室內配線丙級學術科互動練習

這是筆電瀏覽器使用的練習原型，包含 B11 第二題術科圖面接線，以及與電動機相關的 8 題學科入門測驗。術科依官方附圖（二）建立單相感應電動機正反轉主電路、控制迴路、端子台與保護接地，並測試正轉、反轉、停止、電氣互鎖與過載。虛擬端子號與電路運算不等於現場器材的配線指示或安全檢驗。

## 啟動

安裝 Node.js 20.19 以上與 pnpm 後，在本資料夾執行：

```powershell
pnpm.cmd install
pnpm.cmd dev
```

打開終端顯示的本機網址，通常是 `http://127.0.0.1:5173/`。測試用 `pnpm.cmd test`，正式建置用 `pnpm.cmd build`。

## 操作

1. 在左側查看元件；可以拖曳元件到中央調整位置。
2. 選擇線色，依序點兩個端子接線；也可從一個端子拖到另一個端子。
3. 在工作區下方點選已接電線可刪除；點「檢查圖面接線」查看第一個待修正問題。保護接地在此練習使用綠線。
4. 需要時逐層開啟提示，或主動顯示參考接線。
5. 接線通過後，測試正轉、停止、反轉、互鎖與過載。測試由接線與虛擬接點計算。

上方可切換「術科配線」與「學科練習」。學科題目依[勞動部 007003A13 官方學科題庫](https://owinform.wdasec.gov.tw/owInform/DLowFile/007003A13.pdf)工作項目 11「電動機裝置」改寫，依原題號核對答案，作答後立即顯示解析，完成時列出錯題。可單獨重練答錯的題目；下方顯示最近五次完整測驗的成績，錯題重練不計入完整測驗次數。這只是 8 題入門練習，不是完整題庫。

丙級正式學科為 80 題單選、100 分鐘，每題 1.25 分，60 分及格（至少答對 48 題）。四項共用工作項目各抽 4 題，共 16 題；其餘 64 題為專業題。現有 8 題不計正式考試分數，也沒有冒充 80 題模擬考。依據：[技能檢定中心考試說明](https://www.wdasec.gov.tw/News_Content.aspx?n=611E645F4BAB689F&s=C01442902F63E8F8&sms=47C68486FEC19CA4)、[共用題抽題比例公告](https://www.wdasec.gov.tw/News_Content.aspx?n=25D08F3407C71E8F&s=5A79A08661B15374&sms=1BE761BDBCE7C913)、[及格分數規定](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0080014)。

重新整理可恢復未完成接線與學科作答進度。術科完成時間、檢查錯誤、提示次數與學科完成紀錄只儲存在這台電腦的瀏覽器內。清除瀏覽器網站資料會刪除這些紀錄。

## 範圍與限制

程式將官方 `007003B11.pdf` 第二題附圖（二）的每條外部導線表示為虛擬節點。正轉與反轉接觸器各有三組主接點；積熱電驛包含兩組主電路元件及控制接點；TB5、TB1 和馬達以圖面左起位置對應。馬達內部繞組、離心開關與電容僅依官方圖表示，未作類比電氣計算。虛擬測試依所接導線與接點狀態求出線圈、燈號、蜂鳴器及馬達方向，沒有計算電流、電容啟動過程或保護器額定值。圖上沒有印出的實體器材端子號，在程式中均為教學標示。使用前應以官方圖、現場器材型號與指導教師確認實際配線；本程式不會控制真實電源。

圖面節點與教學端子的對照見 `docs/b11-schematic-mapping.md`。舊版草稿在題目升級時會封存於本機瀏覽器，不會當成新版接線恢復。

目前術科只有 B11 第二題，學科只有 8 題示範，沒有帳號、雲端或教師後台。
