# 室內配線丙級 B11 第二題接線練習

這是筆電瀏覽器使用的 B11 第二題圖面練習原型，依官方附圖（二）建立單相感應電動機正反轉主電路、控制迴路、端子台與保護接地，並測試正轉、反轉、停止、電氣互鎖與過載。虛擬端子號與電路運算不等於現場器材的配線指示或安全檢驗。

## 啟動

安裝 Node.js 20.19 以上與 pnpm 後，在本資料夾執行：

```powershell
pnpm.cmd install
pnpm.cmd dev
```

打開終端顯示的本機網址，通常是 `http://127.0.0.1:5173/`。測試用 `pnpm.cmd test`，正式建置用 `pnpm.cmd build`。

## 操作

1. 在左側查看元件；可以拖曳元件到中央調整位置。
2. 選擇線色，依序點兩個端子接線；也可從一個端子拖到另一個端子。
3. 在工作區下方點選已接電線可刪除；點「檢查圖面接線」查看第一個待修正問題。保護接地在此練習使用綠線。
4. 需要時逐層開啟提示，或主動顯示參考接線。
5. 接線通過後，測試正轉、停止、反轉、互鎖與過載。測試由接線與虛擬接點計算。

重新整理可恢復未完成接線。完成時間、檢查錯誤與提示次數只儲存在這台電腦的瀏覽器內。清除瀏覽器網站資料會刪除這些紀錄。

## 範圍與限制

程式將官方 `007003B11.pdf` 第二題附圖（二）的每條外部導線表示為虛擬節點。正轉與反轉接觸器各有三組主接點；積熱電驛包含兩組主電路元件及控制接點；TB5、TB1 和馬達以圖面左起位置對應。馬達內部繞組、離心開關與電容僅依官方圖表示，未作類比電氣計算。虛擬測試依所接導線與接點狀態求出線圈、燈號、蜂鳴器及馬達方向，沒有計算電流、電容啟動過程或保護器額定值。圖上沒有印出的實體器材端子號，在程式中均為教學標示。使用前應以官方圖、現場器材型號與指導教師確認實際配線；本程式不會控制真實電源。

圖面節點與教學端子的對照見 `docs/b11-schematic-mapping.md`。舊版草稿在題目升級時會封存於本機瀏覽器，不會當成新版接線恢復。

目前只有一個題目，沒有帳號、雲端、學科題庫或教師後台。
